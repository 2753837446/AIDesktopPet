# SECURITY.md｜安全与隐私基线

版本：V0.3 · 日期：2026-10-27

# 1. 适用范围

本文定义 Windows AI 桌宠在规范阶段的安全基线，覆盖本地数据、模型调用、长期记忆、任务执行、工具调用、Connector、密钥和安装升级。实现代码建立后，本文件必须随威胁模型和实际架构同步更新。

# 2. 资产与信任边界

需要保护的资产包括：

- 用户消息、记忆、项目状态、任务、提醒和每日总结。
- 邮件、日历、文件及其他 Connector 数据。
- 模型 API Key、OAuth token、Cookie、授权码和诊断包。
- 工具执行能力、审计日志和外部动作结果。
- 应用安装包、更新包、数据库迁移和配置。

信任边界：

- Windows 操作系统、用户凭据库和已签名应用代码属于较高信任边界，但仍需校验输入和更新完整性。
- 模型输出、网页、邮件、文件和 Connector 响应属于不可信输入。
- UI 不能直接访问模型供应商 SDK、数据库业务 SQL 或高权限系统能力。
- 所有外部动作必须经过 Tool Runtime 的 schema、权限、风险和审计检查。

# 3. 主要威胁与控制

| 威胁 | 控制 |
| --- | --- |
| 提示注入诱导模型执行危险动作 | 外部内容与系统指令分离；工具调用始终经过 schema、权限和风险检查 |
| `local_only` 数据被发送到云端 | 上下文组装显式接收处理目的地；发请求前过滤并记录审计 |
| API Key 或 token 泄漏 | 使用 Windows 凭据存储；禁止进入提示词、普通日志、settings 表和诊断包 |
| 模型伪造工具参数或越权 | 模型输出不可信；Tool Runtime 独立校验参数、scope、超时和确认状态 |
| 邮件或外部提交被重复执行 | 稳定幂等键；不确定结果进入 `needs_reconciliation`；先对账再重试 |
| 记忆删除后从索引或缓存泄漏 | 删除事务立即阻断读取；清理队列异步删除 FTS、向量、缓存和派生摘要 |
| 项目记忆串线 | 检索强制项目过滤；项目外键和来源关系完整；跨项目访问需要明确规则 |
| 任务或事件崩溃后卡死 | 持久化租约、心跳、重试次数和恢复扫描 |
| 数据库迁移或断电损坏 | 迁移前检查空间和备份；单事务迁移；失败后停止写入并提示恢复路径 |
| 恶意配置包或角色包 | schema、版本、大小和允许字段校验；禁止配置携带任意代码 |
| AI 姿态把私人图片或提示词误发到外部 | 仅上传当前已确认的单张角色参考图和姿态描述；生成前展示目标、模型、云端处理与可能费用 |
| 生图结果 URL 指向内网或恶意内容 | 只接受公网 HTTPS；校验 DNS/IP、拒绝重定向，立即下载并重新校验图片魔数与大小 |
| 诊断包泄漏私人内容 | 默认脱敏；允许用户预览和选择导出范围 |

角色人格属于表达层配置，只能影响称呼、语气、回复长度和建议方式，不得覆盖固定安全规则、事实真实性、权限或工具确认要求。人格导入包必须校验 schema、版本、字段和 100 KB 大小上限。

# 4. 权限与风险分级

| 风险 | 默认策略 |
| --- | --- |
| low | 在已有授权范围内自动执行，仍需输入校验和审计 |
| medium | 必须匹配授权范围；根据数据敏感度要求确认 |
| high | 展示具体动作、目标和影响，用户确认后执行 |
| critical | 默认不支持自动执行；未来支持时需独立安全设计和二次确认 |

发送邮件、删除文件、向外部服务提交内容、付款、不可逆删除和敏感数据外传不得由模型自行决定执行。

AI 角色姿态属于“向外部服务提交内容且可能产生费用”的高风险动作。第一方设置页或聊天动作导演必须先展示参考角色、姿态描述、模型、云端上传和费用提示，用户点击确认后才可调用。图像模型不能作为工具路由器，也不能读取聊天历史、长期记忆、Key 或其他角色资产；生成图不能触发工具、权限或文件系统操作。

# 5. 密钥与敏感配置

- DeepSeek 与 SiliconFlow 的密钥和 token 使用 Electron `safeStorage`（Windows 下由 DPAPI 保护）或经过验证的安全存储封装。
- 普通 `settings` 表只保存非敏感配置和密钥引用，不保存明文秘密。
- 日志、错误消息、trace 和审计 `details_json` 不得包含完整 token、密码、邮件正文或无关私人文件。
- 审计界面只读取受控摘要，不展示工具完整输入、密钥或邮件正文。
- 用户必须能查看、替换和撤销连接器授权。
- Himalaya 的 QQ 授权码已迁移到 Windows Credential Locker；`config.toml` 只保存 `password.command` 引用。应用日志和审计不得记录授权码、完整邮件正文或附件内容。
- DeepSeek 与 SiliconFlow Key 不进入图像编辑提示词、请求正文或审计。生成请求只包含 `model`、固定保真模板、用户姿态描述和单张参考图的 data URL。
- 生图返回 URL 只允许公网 HTTPS，禁止用户名 / 密码、非 443 端口、私网地址和非 HTTPS 重定向；结果正文最多 10 MiB。

# 6. 数据生命周期

- 原始消息、结构化记忆、全文/向量索引和摘要必须可追溯关联。
- 用户删除记忆后，所有读取路径立即过滤；异步清理完成前也不能从缓存或派生摘要返回内容。
- 删除原始消息时处理来源摘录和依赖该来源的派生记忆，不能留下无来源但仍可检索的隐性副本。
- 低频记忆可以归档，但不能仅因长期未访问而删除高重要度决定。
- 导出、备份、恢复和诊断包必须提供明确范围、失败提示和清理方式。

# 7. 网络与更新

- 所有网络请求设置超时、取消和有限重试，并区分可重试与不可重试错误。
- 外部动作超时后不得直接重试发送类操作，必须先核对真实状态。
- 更新包和应用安装包必须验证来源与完整性；签名方案在打包选型确认后补入本文。
- Connector 只申请实现当前能力所需的最小 scope，并记录授权变化。

# 8. 验证要求

- 恶意邮件、网页和文件内容的提示注入测试。
- 模型输出非法工具参数、越权 scope 和绕过确认测试。
- `local_only` 数据出站检查与日志脱敏测试。
- 记忆删除、来源删除和缓存清理一致性测试。
- 任务/事件租约恢复、幂等和外部状态对账测试。
- 邮件发送和移入已删除必须经过目标、主题和影响确认；结果不确定时必须先核对邮箱状态。
- AI 姿态必须验证确认前无网络调用、取消与超时不保存资产、内网结果 URL 被拒、非法图片不切换形象、原图不被覆盖。
- 安装包、升级、凭据存储、备份和恢复的 Windows 真机测试。
