# Security

版本：V0.1 · 2026-10-28

- 密码使用强哈希，JWT Secret 与 Bootstrap Token 只从环境变量读取。
- 所有 Workspace 查询必须绑定认证用户与 workspace。
- 设备 token 可撤销；不同设备共享账号但不共享本地屏幕和文件。
- API Key 使用服务器环境变量或密钥服务；禁止写入数据库普通字段和日志。
- 模型、邮件、网页和文件内容是不可信输入。
- 高风险工具必须经过权限、确认、超时和审计。
- `device` 和 `local_only` 数据不得上传或发送给云端模型。

## 智能家居安全边界

- 门锁、车库、报警、燃气、加热和其他可能造成物理伤害的设备属于高风险能力。
- 灯光、普通插座和显示类设备可以先列为低/中风险，但必须支持统一撤销授权。
- 场景执行前展示受影响的房屋、房间、设备和预期状态。
- 高风险场景必须二次确认；默认不支持无确认执行。
- 安全联锁、时间限制、人在家判断和危险状态检查必须是确定性逻辑，不得交给 LLM 临时推断。
- 智能家居凭证不进入模型上下文，不写入普通日志和备份之外的公开位置。
- 摄像头、麦克风、精确位置和设备状态按最小采集原则处理。
