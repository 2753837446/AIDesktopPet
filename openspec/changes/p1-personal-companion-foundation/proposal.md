# P1 个人数字伙伴云边基础

## 背景

旧版把“桌宠实例”作为核心对象，会话、记忆和外观都与单机角色目录绑定。新目标是一个用户拥有一个个人数字空间，其中可以存在多个有独立人格、记忆和任务能力的数字伙伴，并通过电脑、手机和 Web 等多设备持续存在。

## 目标

- 建立用户、个人 Workspace、设备、数字伙伴、外观、会话、记忆和任务的稳定领域模型。
- 建立可部署到个人服务器的单一后端，多设备通过 HTTP/JWT 接入。
- 数字伙伴身份与形象分离：换装或换 Avatar 不改变记忆、关系和历史。
- 记忆区分个人共享、伙伴私有、项目与设备私有作用域。
- 提供多个数字伙伴的创建、切换和独立会话。
- 提供任务创建、完成和到期状态。
- 提供可运行的 Web 客户端，并适配桌面浏览器和手机浏览器。

## 成功标准

- 初始化个人 Workspace 后可以创建至少两个数字伙伴。
- 两个伙伴的私有记忆与会话互不串线。
- 同一账号在不同浏览器/设备登录后看到相同伙伴、记忆和任务。
- 更换朋友的外观后，其名称、人格、记忆和历史保持不变。
- 后端可使用 Docker 部署，并对数据目录持久化。
- 类型检查、单元测试、API 集成测试和 Web 构建通过。
