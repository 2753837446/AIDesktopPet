# 智能家居与智能场景后续规划

## 状态

已确认的产品必需能力，**不属于 V1 实现范围**。

## 目标

- 让数字伙伴理解房屋、房间、设备和场景。
- 通过受控 Connector 接入 Home Assistant、Matter、MQTT 或厂商 API。
- 将自然语言意图转换为可解释、可确认、可审计的场景动作。
- 多设备共享家庭状态和场景定义。

## 非目标

- V1 不实现具体设备协议。
- 不让 LLM 直接控制设备。
- 不默认允许门锁、车库、燃气、报警和加热设备自动执行。

## 成功标准

- 设备能力、状态、场景和授权有稳定契约。
- 低风险场景可以确定性执行并可撤销。
- 高风险动作必须确认并记录审计。
- 家庭数据作用域与个人数字伙伴记忆作用域隔离。
