# P3/P4 记忆中心与持久化任务

## 背景

P2 已能持久化对话、写入明确记忆并调用真实 DeepSeek Flash。当前记忆只能在模型上下文中使用，用户不能查看、纠正或删除；任务提醒也尚未实现持久化调度。

## 目标

- 提供记忆列表、搜索、编辑和删除。
- 删除记忆时立即阻断检索并清理 FTS / chunks。
- 新增 tasks、task_runs、notifications 数据表和 migration v2。
- 实现一次性任务创建、状态机、租约、幂等和重启恢复。
- 到期任务通过 Windows 系统通知反馈；失败有稳定错误状态。
- 增加记忆中心和任务中心 UI。
- 用确定性时钟和假通知 sink 测试调度逻辑。

## 成功标准

- 用户可新增任务、查看状态、完成或取消。
- 到期任务只执行和通知一次；重复调用 scheduler 不会重复通知。
- 应用重启后任务状态和到期时间仍存在，过期租约可恢复。
- 用户可修改记忆内容并立即影响后续检索。
- 用户删除记忆后，搜索和记忆中心都不再返回该内容。
- 类型检查、单元测试、Electron 测试、打包和真实 DeepSeek 回归通过。

## 不做

- 本轮不接入 BGE-M3 向量服务。
- 不实现重复任务 recurrence、邮件 Connector 或跨设备同步。
- 不实现高风险工具执行。
