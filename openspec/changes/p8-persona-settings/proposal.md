# P8 角色人格配置

## 背景

PRD 要求角色人格、说话风格、行为边界和主动性可配置。当前 Assistant Core 使用写死的 System Prompt，设置页只能调整角色尺寸。

## 目标

- 增加版本化 persona 配置和内置预设。
- 支持角色名称、自称、用户称呼、人格描述、语气、回复长度、行为边界和主动性偏好。
- Assistant Core 每次请求动态读取当前 persona。
- 安全底座保持不可被 persona 覆盖。
- 支持 persona JSON 导入和导出，并校验 schema、版本和大小。
- 设置页增加可视化人格编辑。

## 成功标准

- 修改人格后无需重启即可影响下一轮模型请求。
- 预设可以一键切换，自定义字段可以单独修改。
- 人格提示词与安全规则冲突时安全规则优先。
- 非法导入包不会修改现有设置。
- 类型检查、单元、E2E、打包和真实模型回归通过。
