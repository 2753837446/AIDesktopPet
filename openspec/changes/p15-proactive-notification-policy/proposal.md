# P15 主动通知策略

## 背景

设置页已提供“启用主动反馈”和免打扰时段，但任务引擎投递通知时没有读取这些设置；用户关闭提醒后仍可能收到系统通知。PRD 还要求类别开关和每日上限。

## 目标

- 任务通知真实遵守主动提醒总开关、免打扰、类别开关和每日上限。
- 通知记录标明 task / email / calendar / daily_brief / system 类别与被抑制原因。
- 被抑制不代表任务执行失败；任务仍完成，且不会反复重试制造通知。
- UI 展示设置并说明被抑制行为。

## 成功标准

- 关闭主动提醒后不出现 Windows 系统通知。
- 免打扰时段内不出现普通通知。
- 关闭某类别后该类别不再通知。
- 当日达到上限后后续通知被抑制。
- 抑制不会导致任务进入失败或重试循环。
- 单元、E2E 和打包回归通过。

## 不做

- 本轮不做多渠道投递队列或通知日历。
- 不降低高风险操作确认要求。
