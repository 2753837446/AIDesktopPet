# P10 角色图片资产与形态切换

## 背景

当前桌宠只有内置矢量角色。用户需要上传自己的桌宠图片并切换形态；产品后续还要支持多视图、2D 骨骼和 3D 角色。

## 目标

- 支持上传透明背景 PNG、GIF、WebP 图片。
- 校验文件大小、真实格式、图片尺寸和安全字段。
- 图片资产持久化到用户数据目录，并在重启后恢复。
- 设置页可预览、选择、删除自定义形象。
- 桌宠立即切换自定义形象；未选择时使用内置角色。
- 建立 Character Runtime 抽象，为多视图、动作状态和 3D 资产预留接口。

## 成功标准

- 图片上传后可在桌宠主舞台显示。
- 选择状态重启后保留。
- 非法文件、过大文件、SVG 和伪造 MIME 均被拒绝。
- 删除当前自定义形象后回退到内置角色。
- 类型检查、单元、E2E、打包和真实服务回归通过。

## 不做

- 本轮不生成 3D 模型。
- 本轮不做自动绑定骨骼。
- 多视图包、表情表和动作序列先完成设计，不实现编辑器。
