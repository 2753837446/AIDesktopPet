# P16 本地备份与恢复

## 背景

长期记忆、任务、审计和角色资产都保存在本地 SQLite 与 userData 文件中，但目前只能导入导出人格。迁移失败、误操作或换机时缺少可恢复手段。

## 目标

- 一键创建完整备份：数据库一致性快照、角色资产、非敏感设置和 manifest。
- 用户可选择备份目录，备份使用版本化格式。
- 恢复前校验备份版本、文件完整性和数据库可打开性。
- 恢复前自动保护当前数据库、设置和角色目录；失败时回滚。
- 恢复成功后安全关闭数据库并重启应用。
- 备份明确排除 API Key、QQ 授权码、缓存和日志。

## 成功标准

- 备份目录可在另一 userData 环境恢复，角色、记忆和任务可见。
- 密钥不属于备份，恢复后 UI 明确提示需要重新配置。
- 非法或缺少数据库/manifest 的目录不能恢复。
- 恢复失败不破坏当前可用数据。
- 单元、E2E、构建和打包通过。
