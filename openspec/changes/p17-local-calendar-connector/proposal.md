# P17 本地日历 Connector

## 背景

每日总结和主动提醒已声明日历数据源，但日历始终显示未连接。用户未提供 OAuth 凭据，最小可用路径是导入标准 iCalendar `.ics` 文件，将日程本地持久化并在今日总结中使用。

## 目标

- 导入标准 `.ics` 文件，校验大小和语法。
- 解析单次 VEVENT 的标题、开始/结束、地点和描述。
- 日程本地持久化，重复导入按来源 UID 幂等。
- Connector 状态显示已连接和最近同步时间。
- 每日总结读取当天真实日程并标记数据源可用。
- 提供模型只读工具查询今天/指定日期日程。

## 成功标准

- 有日历文件时每日总结包含真实日程，不编造。
- 空日历或解析失败明确标记数据源状态。
- 重复导入不产生重复事件。
- 用户可选择 `.ics` 文件，文件不离开本机。
- 单元、E2E、构建和打包通过。

## 不做

- 本轮不做 Google/Microsoft OAuth。
- 不执行日历写入、邀请或删除。
- 不解析复杂 RRULE；重复事件在后续迭代补齐。
