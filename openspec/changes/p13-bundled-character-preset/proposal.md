# P13 内置角色预设与首次导入

## 背景

用户提供了“苏清月”的角色三视图设定稿，希望直接成为可用桌宠。设定稿包含说明文字、表情缩略图和多个视角，不能作为单张透明角色直接使用；手工写入当前用户数据库也无法随安装包分发或在重装后恢复。

## 目标

- 从用户提供的原始设定稿保留可追溯源文件。
- 裁切正面、侧面、背面全身图并提取透明背景。
- 将三视图作为可打包、可版本化的角色预设随应用分发。
- 首次启动幂等导入角色资产，不重复插入；默认选择正面形象。
- 仅在人格仍为未修改的内置默认值时，使用设定图信息初始化姓名和描述。
- 用户已有自定义角色或人格时不得覆盖。
- 打包后的应用能从 `extraResources` 读取预设并通过真实桌宠渲染验收。

## 成功标准

- 透明资产在浅色、深色和棋盘格背景上没有矩形底图或明显边缘残留。
- 正面、侧面、背面均通过格式、尺寸、透明通道和文件大小校验。
- 删除数据库后重启可重新导入；正常重启不会产生重复资产。
- 首次导入后桌宠默认显示苏清月正面全身图，重启后保持。
- 已有自定义形象或自定义人格的设置保持不变。
- 开发模式、unpacked 包和 NSIS 构建资源路径一致。
- 类型检查、单元、E2E、打包和截图验收通过。

## 不做

- 不根据设定图自动生成骨骼、连续动作或 3D 模型。
- 不把设定卡中的文字、缩略图或他人肖像作为角色资产。
- 不修改用户提供的原始图片文件。
