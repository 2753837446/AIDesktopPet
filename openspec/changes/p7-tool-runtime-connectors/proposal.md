# P7 Tool Runtime 与 Connector 基础

## 背景

当前已有模型、记忆、任务和自动总结，但外部能力尚无统一权限与审计层。PRD 要求所有工具和 Connector 调用经过 Tool Runtime。

## 目标

- 实现工具注册、schema 校验、权限 scope、风险分级和执行审计。
- 高风险调用必须确认，预算超时必须终止，支持取消。
- 工具调用持久化，应用重启后仍可查看结果。
- 增加 Connector 注册和状态持久化框架。
- 邮箱 Connector 明确显示“待选择服务商”，不伪造授权或数据。
- 在设置中提供工具中心和连接器状态。

## 成功标准

- 低风险只读工具可在授权 scope 内执行。
- 高风险工具在确认前不执行。
- 非法参数、权限不足、超时、取消和重复幂等请求都有稳定状态。
- 所有调用产生审计记录。
- Connector 状态可持久化和展示，但未配置时不返回外部数据。

## 不做

- 本轮不绑定 Gmail、Microsoft Graph 或 IMAP 具体服务商。
- 不执行发送邮件、删除文件、付款等真实高风险动作。
- 不接入模型 function calling；Tool Runtime 先作为受控执行层。
