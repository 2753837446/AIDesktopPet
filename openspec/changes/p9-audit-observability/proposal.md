# P9 审计与工具可观测性

## 背景

Tool Runtime 已持久化审计日志，但用户界面只能看到最近工具调用的摘要，不能查看权限、确认、失败和取消事件。为满足“执行过程可审计”，需要提供只读审计视图和稳定关联 ID。

## 目标

- 增加审计日志查询接口和 UI。
- 展示时间、动作、结果、原因、trace ID 和工具调用关联。
- 支持按结果和关键词过滤。
- 保持敏感输入和密钥不进入审计。
- 为后续模型 function calling 复用 trace / audit。

## 不做

- 不实现审计删除或远程上传。
- 不执行真实邮件副作用。
- 本轮不接入模型 function calling。
