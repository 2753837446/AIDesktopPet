# P1 Windows 桌宠壳

## 背景

规范基线已经明确首版需要 Windows 优先的 2D 桌宠、透明常驻窗口、拖动、托盘、设置和可跳过的模型配置。当前仓库没有可运行代码，需要用最小切片验证 Electron 桌面壳是否有能力承载后续 Assistant Core、Memory Service 和 Task Engine。

## 目标

- 建立 pnpm workspace 和 Electron + React + TypeScript 桌面应用。
- 提供透明、无边框、可拖动的桌面角色窗口。
- 提供系统托盘，可显示/隐藏桌宠、暂停主动提醒、打开设置和退出。
- 提供可持久化的非敏感设置，包括窗口位置、大小、主动提醒开关和开机自启偏好。
- 在未配置模型时展示明确的基础可用状态，不访问任何模型或外部服务。
- 启用隔离 preload，通过白名单 IPC 暴露最小桌面能力。
- 提供设置存储单元测试、TypeScript 检查、构建和 Electron 烟雾测试。

## 成功标准

- `pnpm dev` 可以启动桌宠窗口。
- 窗口透明、无系统边框、可拖动，且重启后恢复上次位置。
- 托盘菜单可控制显示、隐藏、暂停提醒、设置和退出。
- 非法或损坏的设置文件可以回退到安全默认值。
- 渲染进程不能直接访问 Node.js、文件系统或 Electron 主进程对象。
- `pnpm check` 和 `pnpm test` 通过。

## 不做

- 本切片不接模型、不实现对话。
- 本切片不创建业务数据库或任务调度。
- 本切片不接入 QQ、NapCat、AstrBot、邮件或其他 Connector。
- 本切片不实现语音、自动浏览、3D 或自动更新。
