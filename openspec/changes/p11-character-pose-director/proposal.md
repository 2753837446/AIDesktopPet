# P11 AI 角色姿态导演

## 背景

P10 已支持用户上传 2D 桌宠形象，但形象只能作为静态图片或 GIF 展示。用户希望用自然语言命令桌宠改变姿态，例如“让她坐在凳子上”。如果只做滤镜或在原图上覆盖文字，无法满足角色一致、可回退和后续动作资产积累的需求。

## 目标

- 从当前选中的自定义 PNG/WebP 形象生成新的姿态候选图。
- 只把用户确认过的角色参考图和姿态描述发送给硅基流动图像编辑模型。
- 保留原图与历史姿态，不覆盖任何已有资产。
- 生成结果先预览，用户明确选择后才切换桌宠形象。
- 记录生成来源、提示词、模型和生成时间，支持删除与回退。
- 为后续多视图、表情包、动作关键帧和 3D 参考素材建立可追溯资产链。

## 成功标准

- 用户输入“坐在凳子上”后，界面先展示角色参考图、姿态描述、模型、云端处理与计费提示。
- 用户确认后才调用外部生图服务；取消、超时、限流和服务故障有稳定错误码与可理解提示。
- 生成结果立即保存到受控用户数据目录，不依赖一小时临时链接。
- 生成结果不会自动替换当前形象；用户在预览后点击“设为桌宠”才生效。
- 原图、旧姿态均可继续选择，删除派生资产不删除源资产。
- 运行时校验模型响应、结果 URL、图片魔数、尺寸与大小。
- 单元测试、类型检查、E2E、构建和打包通过。

## 不做

- 本轮不自动绑定骨骼、不生成 Sprite Sheet、不生成 GLB。
- 不声称多视图或单张姿态图具备自由 3D 动作能力。
- 不把聊天历史、长期记忆、API Key 或其他私人数据发送给图像模型。
- 不执行生成图片中的任何文字指令，也不允许图片内容扩大权限。
